# ヌマーカステン風ドクターイエロークイズ

電車の数を数えるクイズゲームです。

## 使い方

1. GitHubリポジトリをクローンまたはダウンロード
2. `index.html`をブラウザで開く
3. 「ゆうちゃん電車スタート！」ボタンをクリックして開始

## GitHub Pagesで公開する方法

1. GitHubにリポジトリを作成
2. 以下のファイルをアップロード：
   - `index.html`
   - `ドクターイエロー写真.jpg`
   - `ドクターイエロー先頭車両.png`
   - `ドクターイエロー中間車両.png`
3. リポジトリの「Settings」→「Pages」で、Sourceを「main」ブランチに設定
4. 数分待つと、`https://[ユーザー名].github.io/[リポジトリ名]/` でアクセス可能

## iPhoneで使用する方法

1. GitHub Pagesで公開したURLをSafariで開く
2. ホーム画面に追加（共有ボタン → 「ホーム画面に追加」）
3. アプリのように使用可能
